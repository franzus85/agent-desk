---
name: weekly-status-report
description: Compile a weekly status report from calendar events and notes.
requires: [calendar.list, notes.search, notes.write]
---

## Steps
1. List this week's calendar events.
2. Search notes for each project mentioned in an event title.
3. Draft a report grouped by project and write it as a new note.

## Verify before finishing
- Every event title appears somewhere in the report.
- No project is mentioned that wasn't found in a calendar event or note.
