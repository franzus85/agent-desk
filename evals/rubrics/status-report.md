# Rubric: Weekly status report

Pass only if all of the following hold:

1. The response reads as a status report a manager could act on — not a raw dump of tool output.
2. It groups information by project, not by which tool produced it.
3. It does not invent projects, dates, or attendees that weren't present in the notes or calendar data it had access to.
4. It is concise — a few sentences per project, not a wall of text.
